# Portfolio Implementation Plan

## Structure
- index.html (single-page portfolio)
- style.css (design system + all component styles)
- script.js (animations, scroll effects, interactivity)
- assets/ (any generated images)

## Sections
1. **Hero** — Name, title, animated tagline, CTA buttons
2. **About / Summary** — Summary paragraph
3. **Education** — Cards with GPA badges
4. **Skills** — Grouped skill pills with icons
5. **Experience** — Timeline card
6. **Projects** — Cards with tech stack tags
7. **Training** — Timeline entry
8. **Certifications** — Grid of cert badges
9. **Contact** — Contact form + links

## Theme
- Background: #0a0a0f (near-black)
- Surface: #111827 / #1a1a2e
- Accent: #2563eb (electric blue) / #60a5fa highlights
- Text: #f1f5f9 white / #94a3b8 muted
- Font: "Inter" from Google Fonts
